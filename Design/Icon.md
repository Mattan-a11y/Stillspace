# Stillspace icon

The shipped icon is generated from original mountain paths and a dark enclosure in RenderIcon.swift. Icon-preview.png records the flattened result. It follows the owner’s simple two-mountain direction. Rebuild by compiling the standalone renderer, passing an output .iconset directory, then using Apple’s iconutil to create Resources/AppIcon.icns. The renderer is an asset tool and is excluded from the app executable.

This is a static .icns compatibility icon. It does not claim adaptive Liquid Glass lighting. A layered Icon Composer document is not currently present, and an adaptive icon remains a future design item.
