# Artwork and media provenance

- First light, Quiet tide and Blue hour: procedural landscapes defined in `Sources/Desktop.swift`, created for this project.
- Northern Drift: original procedural aurora artwork generated by `Tools/RenderDemo.swift`. MP4, GIF, PNG and generator dedicated under CC0 1.0; see `Demo/README.md`.
- `Resources/AppIcon.icns`: mountain paths generated by `Design/RenderIcon.swift`.
- System interface glyphs use Apple's SF Symbols APIs; Apple's applicable terms apply.
- README images render real app views with only the built-in artwork and Northern Drift. No personal imports or third-party wallpaper images are included.
- Synthetic performance clips are generated temporarily and are not bundled.

The application and remaining project assets have no open-source license granted. The CC0 demo dedication applies only to the explicitly listed demo files. No Wallspace catalog or community-uploaded files are distributed here.
